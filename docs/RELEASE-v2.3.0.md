## NetworkSwitch v2.3.0

开启旁路由后，退出程序或重启电脑仍保持旁路由，直到手动恢复。

### 修复与变化

- 路由和 DNS 一起保存。修复临时路由重启消失、静态 DNS 却仍保留的配置不一致问题。
- 后台每 15 秒仅只读检查，不再执行会修改网络的自动修复，避免反复切换。
- 还原失败时保留恢复记录，并禁止后续修复重新添加代理路由。
- “恢复自动”同时清除当前和持久路由；新增“退出（保留当前配置）”托盘菜单。
- 支持手动修复，识别未完整保存的路由；兼容旧版恢复记录。
- 保留 DHCP 地址、原默认网关和 IPv6 设置，不添加开机启动或计划任务。

### 升级

1. 旧版若仍在运行，先还原并退出；留意系统托盘。
2. 退出电脑上的 Clash Verge / VPN / TUN，再运行新版 EXE 并允许管理员权限。
3. 如果提示“旧版临时配置”，先“恢复自动”，再“切到旁路由”。
4. 确认显示“重启保留”；以后重启无需重新运行程序。

新版开启后请使用 v2.3.0 或后续兼容版本还原，旧版不支持新的持久路由恢复记录。
适用网络：`192.168.1.x/24`，旁路由 `192.168.1.192`。
