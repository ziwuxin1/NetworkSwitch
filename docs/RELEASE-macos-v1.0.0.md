# NetworkSwitch for macOS 1.0.0

macOS 首个正式版，支持 **macOS 13+、Apple 芯片和 Intel**。沿用已获用户确认可用的 beta 2 网络逻辑，更新正式版本号与界面标识。

## 功能

- 原生窗口、菜单栏图标、网卡选择、一键切到旁路由及恢复原配置。
- 适用 DHCP 的 `192.168.1.x/24` 家庭网络，目标旁路由及 DNS 为 `192.168.1.192`。
- 保留 DHCP 地址、原默认网关、已有附加路由和 IPv6；保存 IPv4 半默认路由及 DNS，设计为退出与重启后保留。
- 修改前保存恢复记录，失败尝试回滚；后台只读检查。IPv6 系统隧道路由不再误报为 VPN，真实 IPv4 出口冲突仍会被拦截。

## 下载和升级

下载 `NetworkSwitch-macOS-1.0.0-universal.zip`，解压后把 `NetworkSwitch.app` 拖进“应用程序”。

升级时先从菜单栏选择“退出（保留当前配置）”，替换旧应用后重新打开，确认标题显示 **1.0.0**。原恢复记录继续兼容，无需为了升级重新切换网络。

## 验证与签名

正式版使用 macOS 构建机编译通用应用，并执行模拟事务与路由冲突回归检查、应用签名校验、系统只读查询和界面预览。实际结果见附件 `TEST-RESULTS.txt`。

用户已反馈 beta 2 修复版可用；睡眠唤醒、重启和各项恢复场景尚无完整实机验证记录。CI 不执行家庭网络修改。

应用使用 **ad-hoc 签名，尚未经过 Apple Developer ID 签名和公证**。首次打开若被 Gatekeeper 阻止，确认来源后，在“系统设置 → 隐私与安全性”选择“仍要打开”，无需关闭系统安全保护。

退出应用会保留当前配置。离开家庭网络或开启 VPN 前，请先恢复原配置。IPv6 和应用自带代理等仍可能采用其他网络路径。
