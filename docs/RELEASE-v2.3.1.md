## NetworkSwitch v2.3.1

修复 Windows 通知区域显示通用程序图标的问题：托盘现在使用 EXE 内嵌的 NetworkSwitch 图标，与主窗口保持一致。

网关、DNS、恢复记录及重启保留行为沿用 v2.3.0。

### 升级

使用 v2.3.0 的用户：右键旧版托盘图标，选择“退出（保留当前配置）”，再运行 v2.3.1。仅更新此图标修复无需切换网络。

### 下载

- `NetworkSwitch-Cyber-v2.3.1.exe`：独立程序。
- `NetworkSwitch-v2.3.1.zip`：包含程序、源码、使用说明及验证记录。
- `SHA256SUMS.txt`：EXE 和 ZIP 的 SHA-256 校验值。

### 验证

编译成功，15 项模拟界面逻辑检查通过，确认 EXE 的内嵌图标可提取。尚未在真实托盘中目视验证本版本显示，也未执行真实网络切换。
