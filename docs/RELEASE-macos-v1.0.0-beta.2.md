# NetworkSwitch for macOS — 1.0.0 beta 2

修复未安装 VPN 的 Mac 也可能被“检测到 VPN/TUN 出口”阻止切换的问题。

## 修复内容

beta 1 将 IPv6 `utun` 接口上的默认路由或半默认路由直接认定为 VPN。这样的路由不能证明 IPv4 流量正在通过用户安装的 VPN。本工具仅切换 IPv4，因此 beta 2 不再因这些 IPv6 路由阻止切换，也不会删除接口或更改 IPv6。

已有 IPv4 半默认路由、另一个 IPv4 默认出口及持久附加路由的冲突检查仍然保留。错误提示现在显示观察到的接口、网关或路由，不再直接断言安装了 VPN。

## 更新

1. 在菜单栏退出旧版 NetworkSwitch（保留当前配置）。
2. 下载 `NetworkSwitch-macOS-1.0.0-beta.2-universal.zip`，解压并替换“应用程序”中的 `NetworkSwitch.app`。
3. 打开新版，确认窗口标题为 `1.0.0-beta.2`，重新尝试切换。

旧版的这条拦截发生在修改网络前，因此被拦截的那次操作没有写入路由或 DNS。如果已有更早操作留下的恢复记录，新版仍会先要求恢复原配置。

支持 macOS 13+、Apple 芯片与 Intel。仍为 ad-hoc 签名测试版，未经过 Apple 公证；若首次打开被阻止，请在“系统设置 → 隐私与安全性”中选择“仍要打开”。

## 验证边界

macOS 构建机已编译 Apple 芯片和 Intel 通用版，39 项检查通过，包含针对 IPv6 隧道误报、真实 IPv4 隧道冲突、双网卡默认出口及具体错误信息的回归测试，以及原来的事务/恢复测试。应用签名、系统只读查询及下载校验通过，界面预览已检查。具体结果见附件 `TEST-RESULTS.txt`。

构建来源：`03a735458beac16a8a30b6f4e21655e4fd3fd804`；[构建与测试记录](https://github.com/ziwuxin1/NetworkSwitch/actions/runs/40589907862)。

未远程读取用户 Mac 的路由表，也未在家庭网络中执行真实切换、睡眠唤醒或重启验证。此修复针对已确认触发提示的代码分支；端到端联网效果仍需实机确认。
