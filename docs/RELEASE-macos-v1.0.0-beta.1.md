# NetworkSwitch for macOS — 1.0.0 beta 1

首个 macOS 原生测试版，支持 **macOS 13+、Apple 芯片和 Intel**，提供图形窗口及菜单栏图标。

## 下载与使用

下载 `NetworkSwitch-macOS-1.0.0-beta.1-universal.zip`，解压后将 `NetworkSwitch.app` 拖到“应用程序”。不需要安装 Python 或 Homebrew。

选择家庭 Wi-Fi 或以太网，点击“切到旁路由”并完成 macOS 管理员授权。目标固定为 `192.168.1.192`，仅支持 DHCP 的 `192.168.1.x/24` 网络。“恢复原配置”会恢复原来的附加路由及自动/静态 DNS。

## 行为

- 保留 DHCP 地址、原默认网关、已有附加路由和 IPv6 设置。
- 将两条 IPv4 半默认路由和 DNS 保存到 macOS 网络服务，设计为退出程序或重启后保留；无开机启动、后台守护进程或自动修复。
- 后台每 15 秒只读检查；菜单栏可打开窗口、恢复或保留配置退出。
- 修改前持久保存恢复记录；部分失败尝试回滚，未完成恢复时保留备份；检测到外部 DNS/路由变更时停止覆盖。

## 已验证与待验证

macOS 构建机已编译 arm64 和 x86_64，并完成 33 项模拟事务检查、应用 ad-hoc 签名校验、Info.plist 校验及系统只读网卡查询。测试记录作为独立附件提供。

已检查原生窗口预览，下载后的 ZIP 完整性、两种 Mach-O 架构、可执行权限和 SHA-256 校验均通过。预览使用模拟网络数据。

构建来源：`23edc3cb6f5f1cbe390d58e0bbb684cbb6d8a6d5`；[构建与测试记录](https://github.com/ziwuxin1/NetworkSwitch/actions/runs/40587264186)。

**尚未实测家庭网络切换、睡眠唤醒或重启联网。** 首次使用请先测试开启和恢复，再测试重启。IPv6、Private Relay、应用代理及加密 DNS 可能使用其他路径；开启状态不保证外部代理节点可用。

离开家庭网络或启用 VPN 前先恢复原配置。退出应用不会自动恢复。

## 首次打开

本版使用 ad-hoc 签名，**尚未经过 Apple Developer ID 签名和公证**。若 Gatekeeper 阻止打开，确认下载来源后，在“系统设置 → 隐私与安全性”选择“仍要打开”。无需关闭系统安全保护。若 macOS 询问本地网络访问，请允许。

详细说明见附件 `README-macOS.md`。此仓库为私有仓库，下载需要有访问权限的 GitHub 账号。
